# E-Commerce Sales & Customer Analytics

## 📌 Project Overview

This project analyzes e-commerce sales, customer, product, order, and payment data using PostgreSQL and SQL.

The main objective is to extract meaningful business insights from transactional data and understand sales performance, customer behavior, product performance, and payment trends.

## 🛠️ Tools & Technologies

- PostgreSQL
- pgAdmin
- SQL
- GitHub

## 🗂️ Database Tables

The project contains the following tables:

- Customers
- Products
- Orders
- Order Items
- Payments
